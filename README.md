# ClientLocker

## Secure Client Document Management System

ClientLocker is a secure document management platform
designed for accounting firms.

It ensures that employees can access only the client
documents assigned to them.

## Problem Statement

Traditional shared file storage systems can expose
confidential client documents to unauthorized employees.

ClientLocker solves this problem through role-based
access control and secure document management.

## Technology Stack

- Frontend: React.js
- Backend: Python FastAPI
- Database: PostgreSQL
- Authentication: JWT
- Testing: Pytest

## User Roles

1. Partner
2. Staff
3. Client
4. Auditor

## Core Features

- Secure authentication
- Role-based access control
- Private document uploads
- Temporary download links
- Activity monitoring
- AI-based document classification
